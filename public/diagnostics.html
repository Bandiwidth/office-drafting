If the website will not open

Open a terminal in the project folder and run npm start. Keep it open and use the printed address. Read any startup error there. To restart, wait for saved work, press Ctrl+C in that terminal and run npm start again. For missing components, stop the app and run npm run check; follow the setup instructions in the README. Diagnostics shows the actual data folder when the backend is reachable.

No firewall, proxy or Windows security settings are changed by these diagnostics.
