01 · GET READY

Start here

The app is designed for one person on one Windows laptop. It manages the saved documents, facts, formats and files. AI is optional: it helps with language, and it does not confirm facts or issue correspondence for you.

  1. Install Node.js 24 LTS (64-bit) and a current Chrome or Edge browser on Windows 10/11. Download this project and extract it into a writable folder.
  2. Open a terminal in that folder, where package.json is located. Run npm ci --ignore-scripts, then npm run setup. First setup needs internet to obtain the pinned components and advanced PDF editor. Wait for each command to finish successfully.
  3. Run npm start. Keep that terminal open and open the address printed there, normally http://127.0.0.1:4317. The source version does not open a browser automatically.
  4. For later sessions, run npm start again from the same folder. For local AI, start Ollama separately and choose an already downloaded model in Settings.
  5. Wait for Saved locally before stopping. Press Ctrl+C in the app terminal to stop the service. Closing the browser alone leaves the service running.

What is included, and what do I install?

This is a source application for Windows 10/11 x64. Node.js 24 LTS and npm are required; Python and Microsoft Word are not needed for routine drafting and export. The setup commands obtain the document renderer, spreadsheet engine, PDF tools and English/Telugu OCR data. PDF export uses your browser’s Print / save PDF dialog. For local AI, install Ollama and download a suitable model separately. Cloud APIs are optional and need your own key, internet and explicit selection. The app starts with AI off and no saved documents or credentials. Design custom approved DOCX templates in a compatible editor if needed. Windows software policy still applies; do not disable security controls to install this app.

Do not see the website? Go to Solve common problems. This guide cannot open until the local application service is running; the terminal running npm start shows startup errors even when the website is unavailable. Run npm run check from the project folder for component readiness.

03 · YOUR FIRST COMPLETE WORKFLOW

Write your first letter

This practice exercise works with AI disabled. It produces a draft, so you do not need an approved office template just to try it.

  1. In drafting, click New document. You can also use the New document button beside the document title.
  2. Give it a useful title, such as Practice – request for inspection status. The title helps you find the saved task; it is separate from the outgoing Subject fact.
  3. Under What are you writing?, choose Office letter. Choose English and Office / officer for this fictional exercise.
  4. Click Add the facts, or open the Facts tab on the right.
  5. Enter the fictional office, sender/designation, recipient, a real calendar date, subject and requested action. For example: recipient “Depot Manager”; subject “Status of workshop inspection”; action “Please provide the status of the workshop inspection and identify any work that remains incomplete.” Do not invent a real approval or earlier letter.
  6. Check each populated fact and click its Confirm fact button. Optional facts can remain empty if they do not apply.
  7. Click Use template only · no AI when available, or the main Write letter action with AI disabled. Read the generated body on the right. The model-off wording is a basic template draft.
  8. Click Edit body to improve the wording yourself. Wait for Saved locally.
  9. Open Review. Read the issues. An unapproved starter format prevents final export, but you can still download a visibly marked draft.
  10. Click Review & export, choose the draft option, and download Word. Open the downloaded DOCX and check it.

Next, try a reminder using an earlier letter

Start a separate document, choose Reminder, upload the earlier letter as a reference, inspect its text or scanned page, and enter its exact reference and date into Earlier letter reference and Earlier letter date. Confirm those facts against the original. Ask only for the reminder action you actually need. Uploading a previous letter does not itself prove that a reminder was already sent.

For an employee request, choose Employee representation and Employee. For a reply, choose Reply and supply the earlier letter details. Other choices include Official email, Forwarding letter and Internal note. The app prepares email wording; it does not send email.

04 · ACCURACY FIRST

Enter and confirm facts

A fact is a specific detail the application stores separately from the paragraphs: office, sender, recipient, dates, references, subject, requested action, amount, attachments or approval evidence.

  1. Open Facts and enter the exact value. Keep identifiers and amounts as they should appear in the letter.
  2. Use dates in YYYY-MM-DD order, such as 2026-10-26. The date must exist; 2026-13-25 is invalid.
  3. Use the actual reference, not a guessed number. For attachments, enter one named attachment per line.
  4. Inspect the source link when available. An OCR suggestion is a candidate, not a verified fact.
  5. Click Confirm fact only after checking. Editing a confirmed fact makes it require confirmation again.
  6. Return to Review after changing facts. If the action changed after a polished draft was written, regenerate or edit the body to match it.

What the labels mean

  • User supplied: someone entered the value. It is not automatically verified.
  • Extracted: the value came from a document or processing result. It can be wrong.
  • Confirmed: you reviewed and confirmed the value. This is your confirmation, not independent certification by the app.

Protected placeholders

A marker such as {{sender}} means “insert the saved Sender fact here.” Keep its spelling and braces intact. The preview/export substitutes the current value. Do not replace a protected marker with a guessed name or amount. Update the fact itself when a factual value must change.

Sender, recipient, date, subject and requested action are required by the core checks. Reminder and Reply also require the earlier reference and date. Other checks depend on the body, selected template and linked sources. Every populated fact needs confirmation for final export. Approval or sanction language needs supporting evidence; an employee request must not issue officer orders.

Keep verification notes separate. Put actual outgoing content in the body. Review warnings and checking notes belong in the application's review areas, not in the letter you send.
05 · SOURCE MATERIAL

Upload and read references

A reference supplies evidence or background. An approved template supplies a reusable format. Upload each through its own control.

  1. Open the saved document that should own the reference.
  2. Drop a DOCX, PDF, TXT, JPG or PNG into the reference drop zone, or click it to browse. Each file must be at most 12 MB.
  3. Wait until it appears in the references list. Click the file to inspect it. Download the original when you need to compare outside the app.
  4. For a PDF or scan, select English, Telugu, or both, and choose the local processing mode. Click Process reference locally.
  5. Wait for progress to complete. Automatic PDF mode reads selectable text and OCRs pages without selectable text. If a page has a selectable heading but a scanned body, use OCR every page.
  6. Read the extracted text and highlighted uncertain words. Use View page and highlight where offered to compare with the original page.
  7. Review candidate dates/references and conflicts. Import the candidates you actually need, correct them, then confirm them in Facts.

Local extraction and OCR do not use AI providers. Saved extraction can be reused, avoiding repeated work. Reprocessing a reference invalidates confirmations that depend on that source. A successful OCR operation does not mean every word is correct: inspect names, Telugu wording, dates, reference numbers, minus signs and decimal points carefully.

The extraction limit is 30 pages and 200,000 extracted characters; OCR images are limited to 16 megapixels. Split larger inputs. The separate PDF review workspace accepts up to 200 pages, which does not increase this extraction limit.

What uploading does not do: it does not automatically send a whole source file to the language model, turn every sentence into confirmed facts, or reproduce an arbitrary PDF as an exact editable letter format. Enter/import the relevant facts and write a specific request.
06 · FORMATS AND APPROVAL

Choose an office format

Use an existing template

  1. In drafting, click Office templates.
  2. Read the saved format's name, version and approval status.
  3. Select the correct approved format for this document. Built-in starter formats are for drafting.
  4. Use Layout preview if available, then inspect the exported file for final pagination.

Create a reusable DOCX format

  1. Download the template starter from Office templates.
  2. Open it in a DOCX-compatible editor if you need to change its original page design. Add the genuine office letterhead, fonts, margins, spacing and fixed sections.
  3. Keep exactly one {{body}} placeholder. Put it alone in its own paragraph if the body will contain formatting or tables.
  4. Use only supported fact markers. Type markers carefully; unsupported markers are rejected. Do not add macros, embedded objects or external document links.
  5. Save as DOCX. Upload through Office templates, or use the versioning workflow below. Approval must reflect your office's actual decision.

Supported fact markers: {{office}}, {{sender}}, {{recipient}}, {{date}}, {{reference}}, {{subject}}, {{priorReference}}, {{priorDate}}, {{action}}, {{amount}}, {{attachments}}, {{approval}}.

Record a new version and approval history

  1. Open Office centre → Template versions.
  2. Under Previous version, choose the saved version you are replacing, or the option for a new family.
  3. Select the new DOCX, enter a meaningful change reason, and click Upload as draft format.
  4. Under Version, select the new upload. Choose Approve / activate, enter approver name/designation and the reason, then click Record approval action.
  5. Use View approval history to inspect the events. Only one version in a family is active; approving a successor retires the previous active version.

Uploaded bytes are retained as separate versions. Retired or unapproved formats cannot pass new final-export checks. Switch a still-editable document to an approved format when needed. Previously issued copies keep their archived bytes. Approval records are local user assertions, not an electronic grant of authority. Office-specific rules are not built into starter formats; use genuine office guidance and approved templates.

07 · OPTIONAL LANGUAGE HELP

Set up AI assistance

Option A: no AI

Open Settings, select Disabled — template drafting only, and save. You can enter facts, make routine template drafts, edit text, process references, calculate spreadsheets and export without a model. Automatic polishing and translation need an enabled provider.

Option B: Ollama on this laptop

  1. Install Ollama separately and make sure a suitable model is downloaded. The app does not download models for you.
  2. Open Settings. Keep Local-only mode on.
  3. Select Ollama — local models, including Gemma.
  4. Enter the exact installed model name, including its tag, for example gemma3:4b if that model is installed. This is an example, not a promise of speed or Telugu quality on every laptop.
  5. Use the endpoint http://127.0.0.1:11434 for a standard local Ollama installation.
  6. Click Save & test connection. Read the result, then try a short fictional request.

Start Ollama separately before testing the connection; this source application does not start it or download models. Keep the Ollama app running and use ollama list in a separate terminal to check exact installed model names. Do not start a second server if Ollama is already running. A model that advertises cloud-backed execution is rejected. Other local compatible servers need their own local-only configuration.

Option C: another local compatible server

Select Other local OpenAI-compatible server, enter its literal loopback address and exact model name, then save/test. For example, a configured server may use http://127.0.0.1:1234/v1. It must support the response schema the app requests; a server accepting simple chat is not necessarily compatible.

Option D: Gemini, OpenAI or another cloud API

  1. Obtain API credentials from the provider separately. A ChatGPT subscription is not an OpenAI API key.
  2. In Settings, turn off Local-only mode, choose the provider, and enter its model, endpoint where applicable, and key.
  3. Save/test. Read the cloud confirmation before each send. Proceed only if you want the displayed content sent to that provider.
  4. Return to a local provider or disable AI when cloud use is no longer wanted.

The drafting call sends the instruction, current body, entered facts and their confirmation status, with bounded recent drafting context where relevant. Translation sends the necessary source section, protected facts and matching approved terminology. This build does not automatically attach the uploaded source files or all extracted text. Cloud use can have provider charges. There is no automatic provider/cloud fallback. API keys are encrypted for the current Windows user, excluded from backups, and not displayed again after saving.

A connection test checks connectivity, not language quality. Test the selected model on short English and Telugu examples before relying on it for office work.
08 · FROM REQUEST TO WORDING

Draft, revise and format

Ask for a useful draft

  1. Enter the facts first and choose the correct type and writing role.
  2. Describe the actual work and desired action in the conversation. For example: “Write a formal reminder asking the Depot Manager for the status of the workshop inspection. Keep the earlier reference and date. Ask them to identify pending items. Do not claim that approval was granted.”
  3. Use the send arrow, or Enter in the composer. Shift+Enter adds a line. With AI enabled, you can also use Write letter with AI.
  4. Watch the visible progress. Use Cancel writing if necessary.
  5. Read the proposal in the Document panel and any review notes. Choose Accept letter only when satisfied. Until acceptance, the saved body stays unchanged.
  6. Ask for a focused revision such as “Make the second paragraph shorter; retain all dates, names and references.” Review and accept that proposal separately.

With AI off, clearly labelled lines such as Recipient:, Subject: and Action: can populate tentative facts and create a template draft. Free-form wording is not a reliable fact parser in that mode. A short command such as “complete the work” cannot supply the missing details of which work, why, or for whom.

Edit the body yourself

  1. Click Edit body. Type in the body editor and keep protected markers intact.
  2. Choose Formatting tools for bold, italic, underline, lists, alignment, tables and Find/replace.
  3. For a table, set the row/column counts and click Insert table. Keep content within the page width of the approved format.
  4. Wait for Saved locally. Read the preview and Review checks again.

The template controls letterhead, fonts and page layout. Body formatting is supported within those constraints. List numbering is exported as explicit text prefixes rather than Word's automatic numbering. Changing between plain text, formatting and applied translations can affect formatting; inspect the result before export.

If a provider returns changed protected values, invalid structured output, unsupported claims or unusable language, the app can reject the proposal and keep the existing body. Correct the underlying facts or request; do not remove protections simply to force acceptance.

09 · ENGLISH / TELUGU

Translate into Telugu

Typing English does not automatically translate it. You must click Translate to Telugu. Selecting Telugu as the document language does not silently translate an existing English body either.

  1. Configure and test an AI provider in Settings. Use a model that can write Telugu.
  2. Open the desired document, then Office tools → English / Telugu.
  3. Paste your finished English wording into the left pane, or click Use current English body. This route translates written English directly; it does not first rewrite it in English.
  4. Click Translate to Telugu. If a cloud provider is selected, review the send confirmation.
  5. Watch the section progress. The right pane fills with Telugu. You can cancel. Do not edit the source while the translation is running.
  6. Compare the two panes: meaning, paragraph order, names, numbers, dates and reference markers. Correct the Telugu yourself if needed. Matching glossary terms can produce review notes for natural word variations.
  7. Tick I reviewed the meaning, paragraphs, names, numbers and identifiers.
  8. Click Use reviewed Telugu in this document. This applies the Telugu wording to the saved body and replaces its previous body formatting. Inspect Facts, Review and the document preview afterward.
  9. Optionally give the pair a name and click Save new bilingual pair for later review/reuse.

Each pane allows up to 10,000 characters. Longer wording is handled in smaller sections within that overall limit. A failed or cancelled translation keeps the English and restores the Telugu wording present before that attempt; it does not replace the outgoing body. Applying reviewed Telugu is a separate step. If another tab changes the task, reopen Office tools against the current version.

Translate markers, not the fact values

For “Please update the employee record for {{sender}} to reflect the assignment to the {{office}} office,” the surrounding prose should become Telugu and both markers must remain exactly intact. They will resolve to the saved facts in the document. Do not translate the marker names or remove their braces.

If no Telugu is returned, the provider can make one visible correction attempt within the original section deadline. A changed number or protected marker still fails validation. You can try a smaller capable local model or another explicitly selected provider. For a quick check, use a new draft and translate a short sentence through Office tools → English / Telugu. A saved connection test only checks connectivity. The tested Gemma 3 4B model has not met the Telugu quality target; select a more suitable model when necessary. Have a fluent Telugu reader review important outgoing text, and inspect the actual Word/PDF font rendering.

10 · CHECK BEFORE SENDING

Review and download

  1. Accept the intended AI proposal, if one is visible. A previewed proposal is not yet the saved letter.
  2. Check Facts. Correct invalid dates, confirm populated values and inspect linked evidence.
  3. Open Review. Resolve blocking issues, including missing earlier correspondence, unresolved markers, unsupported approval language, stale sources or an unapproved format.
  4. Read the complete document, including the addressee, references, subject, body, signature and attachment list. Confirm your actual authority to issue it.
  5. Tick I have reviewed the complete draft, facts, and authority to issue it.
  6. Click Review & export. Choose Draft or Final copy and download Word or PDF. The bottom export bar also offers Word/PDF and a Final copy checkbox.
  7. Open the downloaded file. Check page breaks, letterhead, margins, tables, signature placement and Telugu characters. Check that all intended attachments are present.

Draft: carries draft marking and can contain unresolved details for review. Final: requires the application's final checks and an approved DOCX format. A final download does not lock the task, dispatch the letter or send email. Use Office centre's separate Issue & lock action for an archived issued record.

Two different PDF paths

  • Letter/document PDF: opens a separate local PDF preview of the checked, saved DOCX. Click Print / save PDF, choose Save as PDF in the browser dialog, use the template paper size with Default margins (the template supplies its page margins), and turn browser headers/footers off. Choose a filename and save. No desktop Office program is required. Allow the preview tab for this local site if your browser blocks it. This is a snapshot; edits require a new preview. Printing does not automatically archive the PDF or mark correspondence as issued.
  • Finance report PDF: uses Print / save PDF and the browser's print dialog after report checks pass. Both PDF paths use the installed browser; neither needs Microsoft Word.

Layout preview is a local browser rendering of the generated DOCX. It helps review the format but does not guarantee identical Word pagination. Browser PDF rendering can change pagination and header/footer spacing; running headers may not repeat on automatic overflow pages. Use explicit page breaks in the approved template where required and check the actual saved file. Telugu PDF copying/searching may split or omit character clusters even when the page looks correct; verify these separately if needed. Automated checks assist review; they do not certify every fact, translation, legal claim or layout.

11 · KEEP AND REVISIT WORK

Save, undo and reopen

  1. After editing a letter or workbook, wait for Saved locally. If an error is shown, resolve it before closing.
  2. Use the left document list to reopen a saved task. The drafting search filters saved documents; Office centre offers a broader content search.
  3. Use body Undo/Redo for recent body edits. These are not substitutes for a backup.
  4. Before a major rewrite, open History → Save a checkpoint.
  5. Select two saved versions and choose Compare versions. Review the displayed changes.
  6. Restore a saved version when appropriate. Restoring keeps later history rather than erasing it. Check current facts and review requirements again.
  7. Use New document for a clean new task. It keeps the previous saved task available.

Office tools library forms, glossary/register forms and template approval forms need their explicit Save, Update or approval action. Unsaved form text is not a saved library entry. PDF recovery has its own Saved locally status and checkpoint controls. AI proposals are not committed body edits until accepted.

To remove an ordinary draft, use History → Delete this document and its references and read the confirmation. It removes active task/source/history records; downloaded copies and older backups can still contain the work. Issued records are locked against ordinary deletion. See issue control for creating a new revision.

12 · REUSE WORK CAREFULLY

Other Office tools

Excel → letter: import a cell as a fact

  1. Save/import a workbook in Finance. Calculate it first if the desired cell is a formula.
  2. In the letter, open Office tools → Excel → letter.
  3. Select workbook, worksheet, cell such as B2, and the destination fact.
  4. Click Review cell, compare with the source, tick the check and click Import fact.
  5. Open Facts and confirm the imported value. Its evidence link identifies the workbook, sheet and cell. A later workbook change requires linked facts to be reviewed again.

Meeting minutes and action tracker

  1. Open Meeting minutes. Enter title, date, attendees and notes.
  2. To use the simple parser, write lines such as Decision: Inspect the workshop next week and Action: Responsible officer | 2026-10-30 | Prepare the inspection checklist.
  3. Click Read labelled decisions and actions. Review the lists and add/correct owners, dates, action wording and status manually.
  4. Click Save meeting & action tracker. To change a saved meeting, open it, edit it, and use Update selected meeting.
  5. Click Create minutes draft when ready. It creates a separate editable document and retains the source meeting.

The parser only reads labelled lines; it does not infer unrecorded decisions or responsibility.

Issue package: a download, not an issued lock

On Issue package, select the original references that belong with the letter, choose Draft or Final, and click Download ZIP package. Every attachment named in the letter must be selected. The ZIP includes the Word letter, selected original attachments and a checksum manifest. Final packages require final checks. This tool does not lock the document; use Register & issue for that.

Batch letters from a workbook

  1. Set up the current document's type, office profile and template.
  2. Choose a saved workbook on Excel → letter, then open Batch letters.
  3. Select the sheet, first/last data row and the column mapping. Up to 50 rows can be processed.
  4. Click Preview letters. Inspect every row, including missing or invalid fields.
  5. Tick the review checkbox and click Save individual drafts. Each letter has unconfirmed facts and cleared approval evidence.
  6. Open and review each new draft before final use. The operation uses templates without AI and does not issue letters automatically.

Make a scan searchable

  1. Upload a PDF or image reference to the current task.
  2. Open Searchable scans, choose the reference and OCR language.
  3. Read and tick the flattened-copy consent, then choose Create & download searchable copy.
  4. Open the result and test its text search/copying. Check OCR accuracy; keep the original.

This supports up to 10 PDF pages or one image. The new copy retains the page appearance with an OCR text layer, but does not retain interactive fields, signatures or original PDF structure. It is not redaction. Interactive/signature form inputs can be rejected.

Drafting blocks and task presets

Drafting blocks: name the wording, choose its language, review it and Save new block. Later search/select, Load block, review it for this task, then Insert loaded block. A reusable paragraph cannot prove an approval or fact.

Task presets: select safe reusable fields from the current task and Save current setup as new preset. Start a new document from preset creates a separate draft. Dates, outgoing numbers, amounts, attachments, approvals and confirmations are excluded so they are not reused accidentally.

13 · LOCAL NUMBERS

Work with spreadsheets

  1. Open Spreadsheets & finance.
  2. Choose Open sample workbook to learn using fictional data, New workbook for manual entry, or Import Excel (.xlsx).
  3. For an import, inspect the worksheet, column/range preview and warnings. Review optional account category suggestions before applying them. Confirm the import using the dialog.
  4. Edit cells directly. Paste a plain tab-separated range with Ctrl+V. Navigate rows using the row controls; the grid shows 50 rows at a time.
  5. Enter a formula such as =SUM(B2:B10) or =ROUND(B2*0.18,2). Choose Calculate formulas and read any errors.
  6. Use Formula audit → Trace dependencies to inspect the source cells of a calculation.
  7. Wait for Saved locally. Use Save checkpoint before large edits. History supports version comparison and restoration.
  8. Choose Excel workbook to export the edited data. Choose Original upload when you need the unchanged uploaded file.

Supported functions are SUM, AVERAGE, MIN, MAX, ABS, ROUND, IF, COUNTA and SUMPRODUCT. Use uppercase function names. Full Excel compatibility, macros, external links, named ranges, dynamic arrays and whole-column formulas are not supported.

Prefix an identifier with an apostrophe, for example '00123, to keep leading zeros. The same technique preserves literal text beginning with an equals sign and long identifiers that should not be treated as numbers. Use XLSX import instead of clipboard paste for quoted/multiline cells.

Any edit clears calculated results and report confirmation; recalculate and review again. Edited XLSX exports preserve the supported cell data/formulas, not the original styling, merged cells, charts, images, comments or validation rules. The original download retains the original bytes. The finance module uses no LLM for calculations.

14 · REPORTS FROM REVIEWED BALANCES

Prepare profit and loss and balance sheets

Use this for internal reports from an unclosed adjusted trial balance: end-date balances for assets/liabilities/equity and the stated period's income/expenses. Current-period profit must not already be included in equity, because the app adds it once. The module does not post journals or derive accounts from arbitrary spreadsheet layouts.

  1. Supply account names, debit amounts, credit amounts and account categories in a workbook.
  2. Open Report mapping. Select the worksheet, four distinct columns, first account row and last account row. Exclude headings and totals.
  3. Enter organisation, currency, period start and period end. Dates label the balances you supplied; they do not filter transactions.
  4. Classify each row as exactly asset, liability, equity, income or expense.
  5. Enter positive debit/credit values with no more than two decimal places. Put a reverse balance in the opposite column. Enter an explicit zero where a zero balance is intended.
  6. Read the basis checkbox, tick it only when correct, then click Confirm mapping & check reports.
  7. Open Financial reports. Resolve the displayed errors and inspect duplicate names, rows with both debit and credit, source cells and reconciliation results.
  8. When checks pass, choose Reports in Excel or Print / save PDF.

A small fictional example

In a new workbook with the default headings, paste this tab-separated example starting at A2. Set the mapping for these six account rows and confirm the reporting basis.

Cash	900.10		asset
Equipment	200		asset
Payable		100	liability
Capital		800	equity
Service revenue		300.10	income
Office costs	100		expense

Expected net profit is 200.10; assets are 1,100.10; equity including profit is 1,000.10; liabilities are 100.00. A balanced result helps check the example, but does not prove that real source classifications are correct.

Compare periods

Save two separate workbooks with valid, confirmed reports for the same organisation and currency. Open Period comparison, choose Earlier workbook and Later workbook, then Compare reports. Review the dates and Download comparison CSV if needed. This compares supplied reporting totals, not underlying transactions.

These are internal reporting tools, not a statutory filing, tax computation or complete accounting system. Correct classification, completeness and the reporting basis remain your responsibility. Financial totals use minor-unit arithmetic; generic spreadsheet formulas have their calculation library's numeric behaviour.
15 · REVIEW PDF FILES

Review and edit PDFs

Basic workspace: notes, highlights, drawings and forms

  1. Open Review & edit PDFs and click Open PDF.
  2. Choose a file up to 12 MB and 200 pages. Use page/zoom controls and Find text.
  3. Select Text note, Highlight or Draw, or fill an existing interactive form. A text note is an annotation; it does not replace existing paragraphs.
  4. Finish the current edit by leaving its editor. Wait for Saved locally, or use Save checkpoint.
  5. Choose Download edited PDF and inspect the saved copy.
  6. To attach it to a letter, choose a saved letter under Save reference to and click Save edited reference. This adds a new reference and retains the original. Process/confirm facts from the new reference separately.

Recovery and selected-page comparison

Expand Reopen a saved PDF to reopen a recovery session. Select a saved version and choose Compare page for a side-by-side view of that page against the current saved version. Restore version adds a new version; it does not erase the later history. Recovery retains the original and latest ten versions per session. Password-protected PDFs and changes inside the separate PdfCraft editor are excluded from this recovery system.

Advanced editor: existing content and pages

  1. Choose Open advanced editor. It is installed by npm run setup. If absent, choose Install advanced editor with internet available, or stop the app and run npm run setup in the project folder.
  2. Open the PDF again inside PdfCraft. Files are not automatically transferred from the basic review tab.
  3. For text editing, choose the app's Edit or delete text helper. Its instructions point to Edit a PDF → Edit text and images; selectable existing text can be selected and deleted where supported.
  4. For page removal, use the Delete pages helper, or Ctrl+K in PdfCraft and search for that command. Review the page range.
  5. For content removal, the helper describes Redact text and images, followed by Apply redactions. Marks alone do not remove content. A scanned word is part of an image, not an editable text paragraph.
  6. Use PdfCraft's own Save controls. Reopen the saved result, inspect all intended changes and upload it to the drafting app if needed.

PdfCraft is an open-source alpha editor, not a guarantee of Adobe feature parity. Existing-text editing, Telugu/non-Latin text and different PDF structures can behave differently. Covering text with a white box/highlight is not secure redaction. For confidential removal, independently verify the saved file's text, copying/searching and other retained content before sharing; this integration does not certify secure redaction. Editing can invalidate digital signatures.

The advanced frame cannot use workspace APIs and has separate file controls. Its changes are not automatically autosaved into the basic PDF recovery session or into a letter reference. Review Telugu font shaping in the saved output, not just in the editor.

16 · REVIEW BEFORE IMPORT

Move PDF tables to Excel

  1. Upload the PDF as a reference to a saved document in drafting.
  2. Open Office centre → PDF → Excel.
  3. Select that document, its PDF reference and the page number, from 1 to 30.
  4. Set the column boundaries as increasing page-width percentages, including 0 and 100. For example, 0,40,70,100 makes three columns: 0–40%, 40–70%, 70–100%.
  5. Choose the OCR language. Use Force OCR if the page is scanned or the text extraction is unsuitable.
  6. Click Preview page table. Compare the rows and cells with the original. Adjust boundaries and preview again if columns are wrong.
  7. Correct every relevant cell, including signs, decimals, dates and identifiers. Yellow cells need attention, but unhighlighted cells can also be wrong. Untick rows you do not want.
  8. Enter a workbook name, tick the review statement, and click Create reviewed workbook.
  9. Open the new workbook in Finance. Review its cell types and mapping. Nothing is automatically approved for financial reporting.

The source PDF stays available as the workbook's Original upload. Formula-like text beginning with = is imported literally, not executed. A preview expires after ten minutes; make a new preview if it expires or the source changes. Identical committed imports reuse the same result, while changed reviewed rows require a new preview.

This is assisted extraction for up to 500 rows and 2–20 columns on one page at a time. Merged, irregular, rotated or complex tables may need substantial manual correction. It does not promise exact workbook recreation from arbitrary PDFs.

17 · CONSISTENT WORDING

Approve Telugu terminology

  1. Open Office centre → Telugu glossary.
  2. Choose New term, enter a short English term and the preferred Telugu wording. Add a usage note explaining the intended context.
  3. Check the translation with someone competent in that terminology.
  4. Tick I approve this terminology for reuse only when appropriate, then click Save term.
  5. For changes, choose the saved term, edit it, and Save term again. Use Clear for new term when adding a different entry.

Only approved entries matching complete terms in the source are offered to translation. The glossary guides wording; it does not establish facts, authority or full-sentence accuracy. Telugu word endings may change naturally in a sentence, so a missing exact term match is a review note rather than automatic rejection or forced replacement. Numbers and protected markers must still be preserved.

There is a 500-term limit. Restored glossary entries need approval again. Resolve restored duplicates before reapproval; do not approve conflicting terminology simply to silence a warning.

18 · RECORD THE OUTCOME

Record, issue and follow up

Record correspondence without locking a document

  1. Open Office centre → Register & issue.
  2. Under Record or update correspondence, choose New entry and Incoming or Outgoing.
  3. Enter the exact reference, subject, sender/recipient and correspondence date. Add a follow-up due date if applicable; it must not precede the correspondence date.
  4. Choose Pending, Replied or Closed. Record dispatch method, acknowledgement and follow-up notes based on what actually happened.
  5. Click Save entry. Later select it under Saved entry, update it and save again. Use the pending-only filter to review follow-ups. Pending overdue items are highlighted.

Saving an entry does not send a letter, prove delivery or create an issued-copy archive. The register holds up to 1,000 entries.

Issue and lock an office document

  1. Complete the letter in drafting. Select an approved template, use Office / officer role, confirm a unique outgoing reference, and resolve all final Review checks.
  2. Open Register & issue and select the document under Saved document.
  3. Inspect its issue details. Enter dispatch method/follow-up information if appropriate.
  4. Read the issue confirmation carefully. Check the final content, authority, reference and attachments before ticking it.
  5. Click Issue & lock. The app archives the exact generated Word file, all current original references and a checksum manifest, and creates the outgoing register record.
  6. Use the issued Word/package download controls for the archived copy. Check it before actual dispatch, then record delivery/follow-up metadata separately.
This action locks the record. Issued body, facts and source references cannot be edited or deleted through ordinary document controls. Issue is a recordkeeping action, not email sending, delivery confirmation, a digital signature or proof that an officer has authority.

Correct or follow up an issued letter

Use Create a new revision in the issue area. It creates a separate editable draft with copied references, facts requiring confirmation, and cleared document date, outgoing reference and approval evidence. Recheck the new draft and assign the appropriate reference before issuing. The original archive remains unchanged. Follow-up and delivery metadata on the original register record can still be updated.

An issue package can contain up to 100 original references totalling at most 32 MB. It archives Word plus originals; it does not automatically include an issued PDF. This is application-enforced immutability, not a cryptographic tamper-proof archive against someone with direct database/file access.

19 · FIND YOUR SAVED WORK

Search saved work

  1. Open Office centre → Search everything.
  2. Enter a few distinctive words, an identifier or Telugu words from the saved content.
  3. Click Search locally. Read the result type and context, then open its link.
  4. If a scan is missing, process its reference text/OCR in drafting first and search again.

Search covers saved document bodies/fact values, extracted reference text, workbook contents, saved wording, glossary and register entries. It uses a local text index, not an AI interpretation of your question. Use up to 12 words/300 characters; results are limited to 100. A very broad query can omit other matches from the result list; try more distinctive wording.

This guide's search only searches help text. The drafting sidebar search filters documents. Office centre search is the one for saved content across modules.

20 · RECOVER AND PROTECT WORK

Jobs, backups and restore

Check a long-running operation

  1. Open Jobs & backups.
  2. Find the OCR, document-export, Excel-import/calculation or export job. Read its status; use Refresh if needed.
  3. Reopen completed saved output using its download/link controls.
  4. If a service restart left it Interrupted, use Retry locally. Retry starts again from saved input; it does not resume halfway through a page.
  5. If the source has since changed, start a fresh operation from the document/workbook. Use Cancel job only for queued/active work; it cannot undo an already committed result.

Supported durable jobs can continue when their browser tab closes while the service remains running. Not every tool uses this queue: AI requests, bilingual translation and PDF-table previews should not be assumed to continue or recover this way. AI requests are never automatically replayed. Job history/output is temporary: cleanup uses seven days or 50 terminal records. Saved letters, original references and workbooks are separate and do not expire with job history.

Create and keep a verified snapshot

  1. On Jobs & backups, click Create backup now.
  2. Wait for its verified ready state. Verification checks file/database integrity, not factual correctness.
  3. Choose Download snapshot to save a .sqlite copy outside the working data folder. Keep an additional copy off the laptop when appropriate.
  4. Configure the schedule and click Save schedule. Defaults are every 24 hours, seven verified copies and a 2,048 MB budget.

The schedule runs only while the service is running and catches up on launch. It is not a Windows task that runs while the app is stopped. Copies on the same disk do not protect against laptop loss.

Restore a snapshot as new copies

  1. If it is already listed, select Restore as new copies.
  2. For a downloaded snapshot, first use Import a downloaded snapshot, choose its .sqlite file and wait for verification. Import only adds it to the backup list.
  3. Choose Restore as new copies afterward to recover its records.
  4. Open the restored work. Recheck facts, templates, financial mappings and source links. Glossary terms require approval again. Issued archives remain locked.

Alternative: JSON backup

Drafting Settings → Download backup exports a JSON backup; Settings → Restore backup imports that JSON format. This is separate from the Jobs page's SQLite snapshot import. Both restore paths add copies rather than replacing existing work. They cover saved documents, references, templates, history, finance, PDF recovery and saved office records/library data. They do not apply provider settings, API credentials or replay saved jobs during restore.

Keys are excluded; unsaved library forms and separate unsaved PdfCraft work are not recovered. Downloaded backups are ordinary unencrypted files. Treat them as sensitive office data. Deleting a live item does not delete its earlier backup copies.

21 · MOVE AND UPDATE THE APP

Offline setup and updates

Normal use after setup

Drafting, installed local extraction/OCR, finance and PDF tools can work without internet. Ollama must have the desired model already available locally. Cloud APIs and obtaining Ollama/models require internet. Complete the initial setup and npm run check before working offline. Components and model weights are obtained during setup, not with each request. A local address does not by itself mean the selected AI provider is local; check Settings.

Install and start the source application

  1. Install Node.js 24 LTS (64-bit) and a current Chrome or Edge browser on Windows 10/11. Download this project and extract it into a writable folder.
  2. Open a terminal in that folder, where package.json is located. Run npm ci --ignore-scripts, then npm run setup. First setup needs internet to obtain the pinned components and advanced PDF editor. Wait for each command to finish successfully.
  3. Run npm start. Keep that terminal open and open the address printed there, normally http://127.0.0.1:4317. The source version does not open a browser automatically.
  4. For later sessions, run npm start again from the same folder. For local AI, start Ollama separately and choose an already downloaded model in Settings.
  5. Wait for Saved locally before stopping. Press Ctrl+C in the app terminal to stop the service. Closing the browser alone leaves the service running.

The GitHub download contains application source and required notices. It excludes saved documents, credentials, dependencies, models and installer binaries. A new installation starts empty; existing work moves only through an explicit backup/restore. Downloaded backups contain sensitive data and should stay outside any public repository. GitHub Pages cannot run this local backend.

Update the source application

  1. Create and verify a backup in Jobs & backups and keep a copy outside the project folder. Save any separate PdfCraft work.
  2. Wait for saves and stop the service with Ctrl+C. Keep the old project folder and data intact.
  3. Extract the new source version into a different folder. Run npm ci --ignore-scripts and npm run setup, then npm start there.
  4. Use the app’s explicit backup restore to transfer saved records. Configure API keys separately. Confirm the expected documents and calculations before using the new version.

There is no automatic rollback button in this source release. To return to an older version, stop the newer service and use the retained older folder with its own compatible data. Do not point old code at a database already migrated by new code. Restoring business data is separate from changing application code.

22 · WHEN SOMETHING GOES WRONG

Solve common problems

“This site can’t be reached” or 127.0.0.1 times out

  1. Open a terminal in the project folder and run npm start. Keep the terminal open and read any error.
  2. Open the printed address with its exact port. A browser refresh cannot start a stopped backend.
  3. If another service owns port 4317, stop the known old app in its terminal. Alternatively set $env:OFFICE_PORT="4318" in PowerShell and run npm start; open the new printed address.
  4. If components are missing, stop the service, run npm run check and follow the setup instructions. Do not disable firewall, proxy or Windows security settings blindly.

Clicking Send opens settings, or the letter does not change

Check the AI provider badge. If you want AI wording, configure and save a provider first. If you want a basic letter, use template-only drafting. After a software change, restart and use the new tab. A visible AI proposal still requires Accept letter; a translation still requires Use reviewed Telugu in this document.

The provider times out, or Telugu is not returned

  1. Keep your original English/body; a failed proposal should not replace it.
  2. Try one short sentence through Office tools → English / Telugu.
  3. Check the exact installed model and run Save & test connection. A connection pass alone does not prove translation ability.
  4. Try a smaller Telugu-capable local model that the laptop can run, selected explicitly in Settings. Do not keep resubmitting the same long request while another is running.
  5. Use Cancel and review the displayed progress/error. Use a separate short draft to check meaning, numbers and protected markers.

There is no automatic cloud fallback. If you select a cloud provider yourself, its existing consent/credential requirements still apply.

“The response removed protected fact {{…}}”

The model omitted or altered required protected content, so the saved draft was kept. Verify the fact and marker spelling, then retry a focused instruction to preserve names, numbers and markers. For an actual factual change, edit the fact and confirm it again. Do not delete a correct protected fact just to bypass the check.

A component is missing

Save work and stop the app with Ctrl+C. Run npm run check in the project folder. To restore dependencies from the lockfile, run npm ci --ignore-scripts, then npm run setup. These setup operations may need internet. Start again with npm start. Do not delete the data folder. A missing optional native component can reflect an unsupported platform or Windows policy; retain the error details.

PDF preview or saving fails

Allow the preview tab for this local website, then use the PDF button again from the saved document. Wait until the preview says Ready. Choose Print / save PDF and select Save as PDF in the browser dialog. Check the template paper size, use default/template margins and switch browser headers/footers off. If rendering fails, retain the DOCX download, check Diagnostics and follow the missing-component setup instructions. A final copy still requires all final checks; printing cannot bypass them.

A fact, source or workbook changed in another tab

The app can refuse an outdated save/import rather than overwrite newer work. Copy any unsaved wording you need, reopen the current record, compare changes and retry. Re-preview PDF tables or re-review linked spreadsheet facts when the source changes.

A file is rejected or processing fails

Read the format, size, page or security error. DOCX reference uploads are separate from templates; XLSX files belong in Finance; PDF table imports start from a saved PDF reference. Split oversized scans and remove encryption using authorised tools when appropriate. Do not rename a file extension to disguise its format. Review Jobs & backups for supported interrupted jobs; start a fresh operation if its saved input is no longer current.

24 · ANSWERS BY TOPIC

Frequently asked questions

Click a question to read its answer. Search includes the answer text even when a question is closed.

Starting, privacy and saving

Do I need internet every time I use the app?

No, once the local components and any local model are installed. Template drafting, local OCR, finance and installed PDF tools can run offline. Cloud AI and first-time downloads require internet. Keep Local-only mode on and select a local provider or disable AI for an offline workflow.

Where are my documents stored?

By default in the data subfolder of the project folder where you run npm start. Set OFFICE_DATA_DIR before starting to choose another writable location. Diagnostics shows the actual data folder and Jobs shows the backup directory. Browser downloads are separate. Keep the data folder and backups private; they are excluded from Git.

Are all my files encrypted?

No. API keys use Windows user-bound encryption, but the database, source files inside it and downloaded backups are not generally encrypted by the app. Use suitable Windows account/device protections. A folder synced by another application can still be cloud-synced; select a non-synced storage location if required.

Does everything save automatically?

No. Letter/workbook editing has autosave, and the basic PDF workspace has its own recovery status. Wait for Saved locally. Office tools libraries, glossary/register forms and approval actions need explicit Save/Update. AI proposals need acceptance; translations need reviewed application; the separate advanced editor needs its own Save/download.

Can I close the browser while processing?

Supported durable jobs can continue while the local service keeps running. Check Jobs & backups before relying on that. AI requests, translation, table previews and the separate PdfCraft editing session are not a promise of recoverable background work. Save ordinary edits and explicit form entries before closing.

Can I open this app from another laptop or phone?

The default service binds to this laptop's loopback address. 127.0.0.1 on another device refers to that other device, not this laptop. Shared network hosting and multi-user access are outside the current one-user, one-laptop scope. Set up the source application separately on the target Windows laptop and use an explicit compatible backup/restore to move work.

Why do I need Restart rather than Refresh after an update?

Refresh reloads the page from whichever service is already running. It does not replace the running backend. Wait for saves, stop the backend with Ctrl+C in its terminal, run npm start in the updated project folder and refresh the browser. Use the address printed in that terminal.

Does New document erase my previous letter?

It starts a separate task and retains previously saved work. Wait for Saved locally before starting. Reopen the old document from the left list. Do not confuse creating a new task with the explicit Delete action in History.

Letters, facts and formats

Can I write a letter with the model switched off?

Yes. Enter the required facts, choose type and role, and use template drafting. Edit the body manually. It uses routine starter wording rather than free-form AI language. Approved templates and final checks are still needed for final output.

What is the difference between a reference and a template?

A reference is evidence/background for a particular task: an earlier letter, order, scan or data source. A template is the reusable DOCX format, including fixed sections and placeholders. Uploading a reference does not make its layout an approved template.

Will uploading a letter fill in and confirm all my facts?

No. Extraction offers text and selected candidate values. Review/import the relevant candidates or enter facts manually. Imported and user-entered values require your confirmation. The app does not establish the truth of a source just because it opened successfully.

Must every fact field be filled?

No. Sender, recipient, date, subject and action are core required fields. Reminder/Reply also need the earlier reference/date. Other checks depend on the task; an issued copy needs a unique outgoing reference. Leave irrelevant optional values empty rather than inventing them. Confirm every value you do enter.

Why is my date rejected?

Use a valid calendar date in YYYY-MM-DD order. For example, 2026-10-26 is valid; 2026-13-25 is not. Check the original rather than interpreting an uncertain OCR date by guesswork. Review earlier-letter/date relationships shown by the checks.

Why do I see {{sender}}, {{office}} or another marker?

It is a protected field marker in editable wording/template text. The app substitutes the corresponding fact for preview/export. Keep the exact marker intact. If the final rendered result still has unresolved markers or required placeholders, resolve the fact/template issue before sending.

Why did a confirmed fact need review again?

Its value or linked source may have changed, a reference may have been reprocessed, a linked workbook updated, or work restored/copied. Confirmation applies to reviewed content, not every future version. Recheck the evidence and confirm again.

Can an employee use an officer's issuing style?

Choose Employee representation and Employee for personal applications/representations. Do not use officer orders such as “hereby direct” without the relevant authority. Office / officer role and an app approval checkbox do not themselves grant authority.

Does ticking a box establish sanction or approval?

No. It records your review/assertion. Supporting evidence is required when the letter claims approval or sanction. The app has targeted checks, but cannot verify every rule, signature or assertion against your organisation's records.

Can the app copy any PDF letterhead exactly?

No. Start with an approved DOCX format. Arbitrary PDF layout recreation is not a dependable feature of this release. Browser preview and exported Word pagination can also differ; inspect the actual output.

What happens when a template version is retired?

New final exports/issues cannot use it. Select an active approved version for an editable task and review the result. Existing issued archives keep their original Word/template record; they are not regenerated with a newer format.

What is the difference between Draft, Final and Issued?

Draft is a visibly marked review copy. Final is an export that passes the current final checks, but the task remains editable. Issued is the separate explicit Issue & lock action: it stores exact Word/reference bytes, creates an outgoing record and locks body/facts/sources. None sends the correspondence automatically.

Will the review warnings appear in my outgoing letter?

The app's verification notes are kept outside the generated document. However, text you manually place in the body becomes document content, and draft exports include draft marking. Read the downloaded file to catch any checking notes you accidentally typed into the body.

AI, translation and writing quality

Can I use Gemma or another Ollama model?

Yes, if it is already installed locally and can follow the required structured-output task. Enter its exact model/tag in Settings. Suitability depends on laptop resources and the model's language ability. The app does not download it or silently switch to a different model.

Can I use Gemini, ChatGPT/OpenAI or other APIs?

Settings supports Gemini, OpenAI and compatible cloud APIs, with explicit cloud consent and Local-only mode turned off. OpenAI uses separate API credentials, not a ChatGPT subscription. Compatible servers must support the requested response format. Select and test the exact provider/model yourself.

Are my uploaded files automatically sent to the AI?

No. This build sends drafting instructions, body, entered facts/status and bounded relevant drafting context; translation sends its source sections and matching approved terms. It does not automatically attach entire source files/extracted text. Anything you paste into the body or request can become provider input, so check cloud consent carefully.

Why is my letter generic or just repeating my action?

Template-only mode uses basic fixed wording. For richer language, enable a capable provider and describe the specific work, background and requested outcome. “Complete the work” lacks that detail. A successful model call is not automatically good writing: review/accept the actual wording and avoid adding invented context.

I see a new letter but the export is still the old text. Why?

Check for the AI suggestion banner. Choose Accept letter after reviewing the proposal; until then, the saved body stays unchanged. In the bilingual tool, review and click Use reviewed Telugu in this document. Wait for saving, then export again.

Does Enter send, or just create a new line?

In the main conversation composer, Enter sends and Shift+Enter adds a line. The send arrow is an alternative. Other text editors/forms can behave differently; typing in the English bilingual pane does not trigger translation.

I selected Telugu. Why is the existing body still English?

The language selector is not automatic translation of previously entered wording. Use Office tools → English / Telugu, put the English on the left, click Translate to Telugu, review the right pane and apply it. An enabled Telugu-capable provider is needed for translation.

Why does translation say the model did not return Telugu?

The selected model returned insufficient Telugu or failed the language checks. One bounded correction may be attempted. Test a short sentence, preserve markers/numbers, and try a more suitable explicitly selected model if necessary. The existing body and prior Telugu are retained on failure; do not keep retrying a long request without checking the cause.

Must the model rewrite my English before translating it?

No. The English / Telugu tool translates your written source directly in small sections. If you want an English rewrite first, request and accept it separately, then use that reviewed wording as the translation source.

Why is there a glossary review note for a correct Telugu ending?

The app can see that an exact preferred term is absent, while Telugu grammar may require an inflected form. Review the sentence meaning and terminology. The note does not force raw string replacement or trigger another model call solely for that variation.

Can the app guarantee a fast answer on my laptop?

No. Inference speed depends on hardware, available memory, model size and request length. Use focused requests and a capable model that fits the machine. Progress/cancel controls and deadlines help manage slow calls, but do not make an unsuitable model fast. No provider fallback occurs without your selection.

Will Cancel undo a letter I already accepted?

No. Cancel stops the active request; it is not a general undo. Accepted/saved changes need the body Undo/history workflow. A cancelled translation restores the pre-attempt Telugu pane and does not apply a new document body.

Does passing validation mean the Telugu translation is perfect?

No. Script, number and marker checks catch some errors, not every change in meaning, grammar or office usage. Have important Telugu reviewed by a fluent reader and verify its rendered Word/PDF appearance.

Excel, calculations and financial reports

Does the language model calculate my P&L or balance sheet?

No. Local application/formula code performs the supported calculations. You supply and confirm the mapping and reporting basis. A model is not used to invent balances or account classifications.

Can I upload any Excel and instantly get correct financial statements?

No. Use an XLSX within the limits, inspect its import and map a suitable adjusted trial balance. Arbitrary transaction lists, formatted schedules or closed balances need preparation. Category suggestions require review and do not establish accounting correctness.

What does “unclosed adjusted trial balance” mean here?

Supply balance-sheet balances at the period end and income/expense balances for that period, after your required adjustments, without having already transferred that period's profit into equity. The module includes current profit/loss in equity once. Ask your accountant to confirm the source basis if unsure.

Why is the balance sheet wrong when profit is already in equity?

The report adds current-period profit/loss to equity. Including it in the source equity as well counts it twice. Correct the reporting basis/source trial balance; do not force classifications merely to make the totals reconcile.

Do period dates filter my spreadsheet transactions?

No. They label the supplied balances and period. The source must already represent the intended reporting period. This module does not post or filter transactions into accounts.

Why did my calculation/report confirmation disappear after an edit?

Edits can change dependencies and reporting amounts, so the app clears previous calculation results and confirmation. Calculate formulas again, review mapping and confirm again before exporting reports.

Why does a valid Excel formula fail here?

The app supports a limited function set and bounded references, not the whole Excel calculation engine. Use supported uppercase functions and inspect Formula audit. Unsupported names, external links, whole-column ranges and dynamic array behaviour need another approach; imported cached answers are not treated as fresh calculations.

How do I keep employee numbers with leading zeros?

Enter them as text with a leading apostrophe, such as '00123. Use the same approach for long identifiers or literal equals-sign text. Check the exported value; do not treat identifiers as amounts just because they contain digits.

Will my original Excel formatting and charts survive an edited export?

No. The supported edited workbook export focuses on cell data/formulas. It does not preserve original styling, charts, images, merged layouts, comments or validation rules. Download Original upload for the unchanged source bytes.

Why does Original upload in Finance download a PDF?

A workbook created from a reviewed PDF table keeps that PDF as its source. Original upload correctly downloads the original PDF. Excel workbook exports the reviewed cells as XLSX. These are different files for different purposes.

How do I download a financial report as PDF?

Confirm mapping and pass the report checks, then choose Financial reports → Print / save PDF. Select the PDF destination in your browser's print dialog and review pagination. Letter PDF export opens a separate local preview with the same browser Save as PDF choice. Neither path requires Microsoft Word.

Do passing reconciliation checks prove the accounts are correct?

No. They check internal relationships such as debits/credits and the accounting equation. Misclassified or omitted balances can still produce balanced totals. Review source cells, completeness, period and accounting basis independently.

PDFs, scans and tables

Can I delete existing content in a PDF?

The basic review tool adds annotations/forms and does not replace existing paragraphs. Open the advanced PdfCraft editor and use the Edit or delete text, Remove content / redact, or Delete pages helper as appropriate. Save and reopen the result. A scanned word is image content; editing text alone will not remove it.

Is drawing a white box or highlighting secure redaction?

No. Covering content can leave the underlying text accessible. The advanced editor describes a separate Apply redactions operation, but this integration does not certify all confidential-data removal. Independently inspect the saved file, including text extraction/search and other retained content, before disclosure.

Why is my PDF not already open inside the advanced editor?

The sandboxed advanced editor has its own Open/Save file controls and is separate from basic review. Open the file there, save/download its result, then upload or reopen that result in the main app if needed. It cannot silently access letter references or workspace APIs.

Does PDF autosave also save my advanced-editor changes?

No. The basic PDF workspace has recovery/checkpoints. The separate PdfCraft editor is excluded, as are password-protected basic sessions. Use the advanced editor's Save controls and retain the downloaded result.

Will editing preserve a digital signature?

Changes can invalidate an existing signature. A flattened searchable scan does not preserve signature structure. Keep the signed original and follow your office's signature/approval process; an edited copy should not be represented as the unchanged signed source.

Does an unhighlighted OCR word mean it is certainly correct?

No. Highlighting reflects engine uncertainty, not complete accuracy. Errors can remain in high-confidence text. Compare important dates, names, amounts, references and Telugu characters against the original image.

Why did OCR miss the body under a selectable PDF heading?

Automatic mode can treat a page with some selectable text as a text page. If the body is scanned, use OCR every page in reference processing, or Force OCR for the table preview. Inspect the resulting reading order and values.

Does a searchable PDF become an editable Word document?

No. It is a flattened PDF copy with OCR text underneath the visible page image. It helps search/copying; it does not recreate the original Word structure, forms or editable letter template.

How do I choose column boundaries for a PDF table?

Use increasing percentages of the full page width, starting at 0 and ending at 100. The intervals form the columns; 0,40,70,100 gives three columns. Preview and adjust against the original. Complex tables may require manual corrections even with sensible boundaries.

Why does the PDF table preview say it expired or changed?

Preview records last ten minutes and belong to the source/version used to make them. Create a fresh preview after expiry or a source change, then review again. Changed rows after an already committed import also require a new preview.

Why does Telugu look different in Word, PDF or an added PDF note?

Font availability, shaping and the rendering engine matter. The app's draft font choice does not guarantee every exported/edited PDF will render identically. Inspect the saved file with suitable Telugu fonts installed. Do not assume that the presence of Unicode text proves visual correctness.

Register, issue, backups and release scope

Does saving a register entry send or issue the letter?

No. It records correspondence metadata. Issue & lock is a separate action and still does not send email/post or establish delivery. Record dispatch/acknowledgement based on the actual external action.

Does Office tools → Issue package lock the task?

No. It downloads a Word-and-selected-annexures ZIP. Office centre → Register & issue → Issue & lock creates the immutable issued archive and outgoing entry. The names are similar, but the actions differ.

How do I fix an issued letter?

Use Create a new revision in Office centre. It creates an independent draft, clears date/reference/approval evidence and requires fact confirmation again. Review and issue the revision with the appropriate new details. The original issued bytes stay locked; follow-up metadata remains editable.

Does the issued archive include a PDF or digital signature?

The current archive contains the generated Word file, original references and checksum manifest, not an automatically generated issued PDF or digital signature. Use the archived Word/package controls for that exact issued record. Do not regenerate an issued task with a newer template.

Will I get automatic deadline notifications?

The current register can highlight pending overdue entries when viewed and offers a pending-only filter. Scheduled desktop notifications and the proposed app-opening reminder module are not implemented in this release. Check your register as part of the daily routine.

Should I import my backup in Settings or Jobs & backups?

Use Settings → Restore backup for the downloaded JSON format. Use Jobs & backups → Import a downloaded snapshot for .sqlite. Importing a snapshot verifies/lists it; choose Restore as new copies afterward to add its business records.

Will restore overwrite my current records or unlock issued letters?

No. Restore adds independent copies and remaps their links. Recheck restored facts/mappings/terminology; issued archived copies retain their locks and bytes. Provider settings/keys are not applied and jobs are not replayed. Repeating restore can create additional copies.

Will my API key work automatically after moving to another computer?

No. Keys are excluded from backups and the source distribution and encrypted for their original Windows user. Configure credentials separately on the target installation. The source download also excludes model weights and saved documents.

Will automatic backups run when the app is stopped?

No. The schedule is in the running application service. It catches up at launch. Closing only the browser can leave the service running, but stopping the service or shutting down Windows stops its scheduled work.

Does deleting a document remove all traces of it?

No. Older backups, downloaded files and external copies may remain. Ordinary SQLite deletion is not a promise of forensic erasure. Issued documents also cannot be removed through normal draft deletion.

Is release rollback the same as restoring yesterday's data?

No. This source release has no managed release rollback. Retain the previous project folder and a verified backup before updating. Stop the service before changing versions. Use each version with compatible data; do not open a newer database in older code. Business-data recovery uses an explicit compatible backup restore.

Why is my scanned reference absent from Search everything?

Only extracted text can be indexed. Process the scan locally first, inspect that its text was saved, then search for distinctive words. Use fewer words if necessary. The guide search and drafting sidebar search do not search the same set of records.

Does the app guarantee there are no errors?

No. It enforces many structured rules and has automated checks, but cannot certify every fact, language choice, account classification, PDF edit or page layout. Review real outputs, use backups and validate representative office examples on your laptop before depending on a workflow.

Are case files and automatic source-based replies available now?

No. Grouped case files, drafting from selected correspondence, paragraph-by-paragraph AI acceptance, local reminder notifications and batch scan intake are planned next-release candidates. The current reference workflow is extraction, reviewed candidate/manual facts and explicit drafting instructions. This guide describes implemented controls rather than treating proposals as finished features.

25 · A RELIABLE ROUTINE

Your daily checklist

  1. Start: run npm start, open the printed address and choose the intended provider. Check local/cloud mode before sensitive work.
  2. Prepare: choose type/role and approved format. Upload relevant references to the right document.
  3. Verify: check original evidence, exact references, dates, names, amounts and attachments. Confirm facts deliberately.
  4. Write: make a template draft or request specific AI wording. Review proposals and apply only the intended one.
  5. Check language: review English/Telugu meaning and protected values; check the saved rendered text.
  6. Check output: resolve Review issues and open the actual Word/PDF or workbook/report export.
  7. Record: issue/lock only when ready and authorised. Record actual dispatch, delivery and follow-up separately.
  8. Protect: wait for Saved locally, save explicit library/forms, check backups and retain an appropriate external copy.
