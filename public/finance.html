Type =SUM(B2:B10) for a formula. Start text with an apostrophe to preserve leading zeros or a literal equals sign. Tab moves between cells; Ctrl+Z undoes text in the focused cell. Workbook Undo restores the previous edited field. Paste a tabular range with Ctrl+V.

Cell outputs appear below formulas after calculation. Any edit clears previous calculation results and report confirmation. Supported functions: SUM, AVERAGE, MIN, MAX, ABS, ROUND, IF, COUNTA, SUMPRODUCT. Full Excel compatibility is not claimed.
