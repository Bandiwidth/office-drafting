ADVANCED EDITING

PdfCraft

Open-source page organisation, combining, splitting, forms and editing tools.

Choose Install advanced editor while online, or stop the app and run npm run setup in the project folder. A local official ZIP can be supplied with npm run setup -- --archive PATH. Normal use is offline after setup.

PdfCraft is alpha. Its text editing and non-Latin OCR need further validation. Files opened there are saved using its own download controls.
